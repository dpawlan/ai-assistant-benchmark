# Vestra

Site: https://vestra.ai/

Vestra is an 'agent office': an executor agent (Bash) plans and runs tasks on its own cloud computer with specialist sub-agents, and a memory agent (Nami) keeps context and suggests work on its own. You can reach it from the Mac app, the web, iMessage, WhatsApp, Telegram, Slack or by email. Requested via the form (issue #211).
