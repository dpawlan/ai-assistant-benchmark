# SLICC

Site: https://www.sliccy.com/

SLICC is an open-source, browser-native AI agent that runs entirely client-side in a Chrome side panel, using the user's existing logged-in sessions to drive web apps such as GitHub, Gmail, Slack, Jira, Outlook and ServiceNow, run shell commands in a WASM shell and coordinate parallel agents. It also ships as a global npm CLI, a macOS launcher and an iOS TestFlight beta, with source on GitHub under Apache-2.0. Requested via the form (issue #311).
