# Doti

Site: https://heydoti.co/

Doti is an assistant that lives inside LINE: add it as a friend and ask for lookups, plans and daily routines in chat. It keeps a notebook of every request, queues tasks and works through them in order, keeps working while you are away and reports back, runs each user in an isolated sandbox, and can sign in to sites with a password kept in a vault it can use but not read. LINE only, so testing needs a LINE account. Requested via the form (issue #375).
