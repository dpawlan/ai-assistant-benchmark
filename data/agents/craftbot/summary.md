# CraftBot

Site: https://github.com/CraftOS-dev/CraftBot

CraftBot is an open-source, self-hosted agent harness that builds and operates its own tools, with 40-plus agent role profiles, 120 playbooks, a memory system that consolidates what happened, proactive planning with approval, connectors for Google Workspace, Slack, Notion, Telegram and Discord, 150-plus MCP servers, a browser UI and a CLI. Bring your own model or run one locally. Requested via the form (issue #405).
