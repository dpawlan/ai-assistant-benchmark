# Hermes Agent

Site: https://hermes-agent.nousresearch.com/

Hermes Agent is Nous Research's open-source, self-hosted agent with a messaging gateway for Telegram, Discord, Slack, WhatsApp, Signal and email, plus a desktop app and CLI. It keeps persistent memory, writes its own skills, runs natural-language scheduled jobs unattended, delegates to isolated subagents, and can browse the web. MIT licensed; you supply the model access. Requested via the form (issue #381). Same category as OpenClaw: needs a self-hosted setup before testing.
