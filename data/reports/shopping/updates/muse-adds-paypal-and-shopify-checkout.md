Muse announced native checkout through PayPal and Shopify merchants this morning. Until now, stores that forced a guest checkout form were the one place Muse would stall, sending a link for you to finish yourself.

We re-ran the purchasing task the same afternoon on a Shopify roaster. Muse completed a two-bag order in one message, asked before charging, and returned the order number with the delivery window. Instinct, run on the same prompt an hour later, staged the same order but stopped at its card link as before.

This moves Muse from a tie with Instinct to a clear first, and it is now our pick.
