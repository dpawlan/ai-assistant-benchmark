# ChatGPT Work

Site: https://chatgpt.com/

ChatGPT Work is OpenAI's mode for delegating tasks inside ChatGPT: it breaks a goal into steps and uses files, plugins, approved tools and a browser to deliver reviewable docs, analyses, recurring updates and workflows, on the web and in the ChatGPT desktop app. Requested via the form (issue #183).
