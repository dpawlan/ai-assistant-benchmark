Subject: Help test Assistant Benchmark with your own assistant conversations

Hi!

I'd love your help testing a new way to contribute to Assistant Benchmark using conversations you've already had with an AI assistant.

You'll need a Mac with Codex or Claude Code and Node 22.13 or newer. No GitHub access, account or invitation code is required. Start with one assistant and a short date range.

Save and unzip the attached assistant-benchmark-contributor.zip into a new folder, then open that folder in your local agent. Paste this:

"Help me install and use the Assistant Benchmark contribution skill from this extracted folder. Do not clone a GitHub repository. Check Node is 22.13 or newer. For Codex run node scripts/install-contribute.mjs --agent codex; for Claude Code use --agent claude. If a skill is already installed, inspect it before replacing anything. Read the installed contribute-runs/SKILL.md and follow it. Check intake readiness first, then ask which assistant and date range I want to contribute. Ask permission before accessing conversations, help me redact personal details, and show the complete preview. Ask for my explicit confirmation before sending. Give me the receipt after submission; do not publish anything."

For Messages, you'll identify the assistant number when asked. The package contains no personal phone mappings. WhatsApp text exports and dated text imports are also supported. The attached guide has more details.

Please review every excerpt: automatic redaction can miss personal details, and your agent provider may process excerpts under its settings. Public excerpts are off by default. I review the evidence and approve any final score before publication; approved scores, notes, attribution and disclosures may appear publicly. Pilot contributions don't change headline rankings. Private submissions expire from the intake after 90 days.

Reply with your receipt ID and anything confusing or cumbersome. If you get stuck, send the error message, not raw conversations. You can also reply with your receipt to request a correction or withdrawal.

Thanks!
David
