# Kith Rabbit

Site: https://kithrabbit.com/

Private relationship-memory agent from Haah that you chat with about people you meet; it builds an interactive map of your connections, answers who-can-help questions, finds warm introductions, sets reminders and imports LinkedIn data. It runs on iPhone, iPad, Mac, Android and a beta web app. Requested via the form (issue #199).
